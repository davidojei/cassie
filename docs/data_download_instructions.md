# Data Download Instructions

The Olist dataset is **not** committed to this repository (license terms +
repo bloat). Download it yourself:

1. Create a free Kaggle account if you don't have one.
2. Go to: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce
3. Download the zip (or use the Kaggle CLI):

   ```bash
   pip install kaggle
   # place kaggle.json (API token, from Kaggle account settings) in ~/.kaggle/
   kaggle datasets download -d olistbr/brazilian-ecommerce -p data/raw/ --unzip
   ```

4. Confirm the following files land in `data/raw/`:

   - `olist_customers_dataset.csv`
   - `olist_geolocation_dataset.csv`
   - `olist_order_items_dataset.csv`
   - `olist_order_payments_dataset.csv`
   - `olist_order_reviews_dataset.csv`
   - `olist_orders_dataset.csv`
   - `olist_products_dataset.csv`
   - `olist_sellers_dataset.csv`
   - `product_category_name_translation.csv`

5. Optionally also grab the **Olist Marketing Funnel Dataset**
   (https://www.kaggle.com/datasets/olistbr/marketing-funnel-olist) into
   `data/raw/` if Phase 2's audit finds it useful to join in.

`data/raw/` is gitignored — nothing here gets committed. `data/synthetic/`
(generated by `scripts/generate_synthetic_data.py`, built in a later
phase) and `data/processed/` are also gitignored except for a tracked
`README.md` describing what should be there.
